#+TITLE: A portable Emacs for modern Linux distributions
#+AUTHOR: Tim Felgentreff
#+PROPERTY: header-args :eval never

* Objectives

I want a portable Emacs package, built regularly from ~master~. I used to build
Emacs locally on every machine I used and selected the features I want: PGTK,
native compilation, tree-sitter, ImageMagick, XWidgets, D-Bus, file
notifications, sound, SVG, XPM, and the common image formats.

I use immutable distributions, WSL2, and Linux on my Android phone through the
Android Virtualization Framework, and I do not want to rebuild Emacs in all
these places, but I get annoyed when I start using a feature on one machine and
then switch to another where it is missing.

This repository is my attempt to make this easier. I first tried Flatpak and
then AppImage, but I always ran into problems, and the git history still
contains some of these experiments. I finally settled on an archive of a
prefixed installation, with some dependencies copied into it and the ELF files
changed using ~patchelf~. Some reasons for this design:

1. One artifact per architecture must run on current Debian, Ubuntu, Linux
   Mint, and Fedora systems.
2. Emacs and all of its subprocesses must have ordinary host access.
3. Installation must not require root access.
4. Libraries, modules, helper programs, data, and the portable dump must remain
   integrated after the prefix is moved.
5. Neither Emacs nor its subprocesses may depend on ~LD_LIBRARY_PATH~,
   ~GCC_EXEC_PREFIX~, ~COMPILER_PATH~, ~LIBRARY_PATH~, or similar shenanigans that
   might confuse other subprocesses.
6. To avoid issues with system integration, use GTK from the host; this implies
   using a bunch of other related libraries from the host as well, such as GIO,
   WebKitGTK, Glib and quite a few more.

* The builder

I build in Debian 12, its glibc is old enough that the binaries should work on
current distributions, and its GTK and WebKitGTK versions are also available on
the distributions I use. The image only contains the tools and headers needed
to build Emacs, it is not part of the package.

#+begin_src dockerfile :tangle Containerfile
FROM debian:bookworm

ENV DEBIAN_FRONTEND=noninteractive

RUN apt-get update && apt-get install -y --no-install-recommends \
      autoconf automake binutils build-essential ca-certificates file git \

      libgpm-dev libgtk-3-dev libharfbuzz-dev libjpeg-dev \

      python3 pax-utils texinfo zstd \

* Building Emacs

The build script can use a different repository, revision, output directory, or
GCC through environment variables, by default it builds the current Emacs
~master~ for the machine where the container runs. I use the same architecture
names for all release files, and stop early if the requested architecture does
not match the machine.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
#!/usr/bin/env bash
set -euo pipefail
trap 'status=$?; printf "build-bundle failed at line %d (status %d): %s\n" "$LINENO" "$status" "$BASH_COMMAND" >&2' ERR

ROOT=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)
BUILD_DIR=${BUILD_DIR:-"$ROOT/.build"}
PREFIX_DIR=${PREFIX_DIR:-"$ROOT/.prefix"}
OUTPUT_DIR=${OUTPUT_DIR:-"$ROOT/dist"}
EMACS_REPOSITORY=${EMACS_REPOSITORY:-https://github.com/emacs-mirror/emacs.git}
EMACS_REF=${EMACS_REF:-master}
JOBS=${JOBS:-$(nproc)}
GCC_VERSION=${GCC_VERSION:-12}
BUILD_GCC=${BUILD_GCC:-gcc-$GCC_VERSION}
BUILD_GXX=${BUILD_GXX:-g++-$GCC_VERSION}
GCC_TRIPLET=$($BUILD_GCC -dumpmachine)

machine=$(uname -m)
case "$machine" in
    x86_64|amd64) machine=x86_64 ;;
    aarch64|arm64) machine=aarch64 ;;
    *) printf 'Unsupported build architecture: %s\n' "$machine" >&2; exit 1 ;;
esac
BUNDLE_ARCH=${BUNDLE_ARCH:-$machine}
case "$BUNDLE_ARCH" in
    x86_64|amd64) BUNDLE_ARCH=x86_64 ;;
    aarch64|arm64) BUNDLE_ARCH=aarch64 ;;
    *) printf 'Unsupported bundle architecture: %s\n' "$BUNDLE_ARCH" >&2; exit 1 ;;
esac
if [[ $BUNDLE_ARCH != "$machine" ]]; then
    printf 'Native build architecture %s does not match requested %s\n' \
        "$machine" "$BUNDLE_ARCH" >&2
    exit 1
fi

rm -rf "$BUILD_DIR" "$PREFIX_DIR"
mkdir -p "$BUILD_DIR" "$OUTPUT_DIR"
rm -f "$OUTPUT_DIR"/Emacs-*.tar.zst "$OUTPUT_DIR"/Emacs-*.tar.zst.sha256

printf 'Cloning Emacs %s...\n' "$EMACS_REF"
git clone --depth 1 --branch "$EMACS_REF" "$EMACS_REPOSITORY" "$BUILD_DIR/emacs"
cd "$BUILD_DIR/emacs"
#+end_src

Once the checkout is ready, I configure the Emacs features I want and do a
bootstrap build, then install through ~DESTDIR~, which gives me a separate tree
to change without touching the container's ~/usr~.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
./autogen.sh
CC="$BUILD_GCC" CXX="$BUILD_GXX" ./configure \
  --prefix=/usr \
  --with-pgtk \
  --with-native-compilation \
  --with-tree-sitter \
  --with-imagemagick \
  --with-dbus \
  --with-file-notification=inotify \
  --with-xwidgets \
  --with-modules \
  --with-rsvg \
  --with-xpm \
  --with-sound=alsa \
  CFLAGS='-O2 -g0'

printf 'Building Emacs bootstrap...\n'
make bootstrap
printf 'Building Emacs...\n'
make -j"$JOBS" all
printf 'Installing Emacs into %s...\n' "$PREFIX_DIR"
make install DESTDIR="$PREFIX_DIR"
printf 'Emacs installation completed.\n'
#+end_src

The installed version and architecture names come from the installation rather
than assumptions about Emacs naming rules.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
printf 'Inspecting installed Emacs...\n'
shopt -s nullglob
version_dirs=("$PREFIX_DIR"/usr/share/emacs/[0-9]*)
if ((${#version_dirs[@]} != 1)); then
    printf 'Expected one Emacs version directory, found %d\n' "${#version_dirs[@]}" >&2
    exit 1
fi
EMACS_VERSION=${version_dirs[0]##*/}
arch_dirs=("$PREFIX_DIR/usr/libexec/emacs/$EMACS_VERSION"/*)
if ((${#arch_dirs[@]} != 1)); then
    printf 'Expected one Emacs architecture directory, found %d\n' "${#arch_dirs[@]}" >&2
    exit 1
fi
EMACS_ARCH=${arch_dirs[0]##*/}
PACKAGE_NAME="Emacs-${EMACS_VERSION}-${BUNDLE_ARCH}"
OUTPUT_NAME="${PACKAGE_NAME}.tar.zst"
#+end_src

* Bundling private libraries

Some dependencies are part of the package, while GTK and WebKitGTK come from
the host, because a bundled GLib does not mix well with GTK modules from the
host, I find all host-side dependencies and do not copy these libraries.

ImageMagick is different: its libraries, modules, and configuration must match.
I copy these files to fixed locations, together with ~libgccjit~ and
tree-sitter, before finding the other libraries they need.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
printf 'Deploying runtime dependencies...\n'
resolve_library() {
    local soname=$1 path
    path=$(ldconfig -p | awk -v soname="$soname" '$1 == soname { print $NF; exit }')
    if [[ -z $path || ! -e $path ]]; then
        printf 'Cannot find required library %s\n' "$soname" >&2
        exit 1
    fi
    printf '%s\n' "$path"
}

elf_soname() {
    readelf -d "$1" | awk -F'[][]' '/SONAME/ { print $2; exit }'
}

private_lib="$PREFIX_DIR/usr/lib/private"
mkdir -p "$private_lib"

magick_libdir=$(pkg-config --variable=libdir MagickWand-6.Q16)
magick_wand=$(find "$magick_libdir" -maxdepth 1 -type l -name 'libMagickWand-6.Q16.so.*' -print -quit)
magick_core=$(find "$magick_libdir" -maxdepth 1 -type l -name 'libMagickCore-6.Q16.so.*' -print -quit)
magick_version_dir=$(find "$magick_libdir" -maxdepth 1 -type d -name 'ImageMagick-*' -print -quit)
magick_modules_dir=$(find "$magick_version_dir" -maxdepth 1 -type d -name 'modules-*' -print -quit)
magick_config_dir=$(find "$magick_version_dir" -maxdepth 1 -type d -name 'config-*' -print -quit)
magick_coders_dir="$magick_modules_dir/coders"
magick_filters_dir="$magick_modules_dir/filters"
magick_share_source=/usr/share/ImageMagick-6
magick_etc_source=/etc/ImageMagick-6
for required in "$magick_wand" "$magick_core" "$magick_config_dir" \
                "$magick_coders_dir" "$magick_filters_dir" "$magick_share_source" \
                "$magick_etc_source"; do
    if [[ ! -e $required ]]; then
        printf 'Cannot locate ImageMagick resource %s\n' "$required" >&2
        exit 1
    fi
done

mkdir -p "$PREFIX_DIR/usr/lib/ImageMagick/config" \
         "$PREFIX_DIR/usr/lib/ImageMagick/coders" \
         "$PREFIX_DIR/usr/lib/ImageMagick/filters" \
         "$PREFIX_DIR/usr/etc" "$PREFIX_DIR/usr/share"
cp -a "$magick_config_dir"/. "$PREFIX_DIR/usr/lib/ImageMagick/config/"
cp -a "$magick_coders_dir"/. "$PREFIX_DIR/usr/lib/ImageMagick/coders/"
cp -a "$magick_filters_dir"/. "$PREFIX_DIR/usr/lib/ImageMagick/filters/"
cp -a "$magick_etc_source" "$PREFIX_DIR/usr/etc/"
cp -a "$magick_share_source" "$PREFIX_DIR/usr/share/"
#+end_src

The installed library names come from the builder rather than being hard-coded.
I mark ImageMagick, ~libgccjit~, and tree-sitter as private roots; everything
linked directly by Emacs is considered part of the host unless it is one of
those roots.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
libgccjit_root=$(resolve_library libgccjit.so.0)
tree_sitter_root=$(resolve_library libtree-sitter.so.0)
magick_wand_soname=$(elf_soname "$magick_wand")
magick_core_soname=$(elf_soname "$magick_core")
libgccjit_soname=$(elf_soname "$libgccjit_root")
tree_sitter_soname=$(elf_soname "$tree_sitter_root")

declare -A private_root_seen=()
private_root_seen[$magick_wand_soname]=present
private_root_seen[$magick_core_soname]=present
private_root_seen[$libgccjit_soname]=present
private_root_seen[$tree_sitter_soname]=present

declare -A host_library_seen=()
host_library_names=()
#+end_src

A few ImageMagick dependencies have incompatible SONAMEs across the supported
distributions and are not part of the GTK/WebKit platform, so I always keep
these inside the archive.  This includes libjpeg: Debian Bookworm provides
~libjpeg.so.62~, whereas Ubuntu 24.04 provides ~libjpeg.so.8~.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
declare -A forced_private_library=(
    [libbz2.so.1.0]=present
    [libfftw3.so.3]=present
    [libgomp.so.1]=present
    [libjpeg.so.62]=present
    [liblqr-1.so.0]=present
    [libltdl.so.7]=present
)
add_host_library() {
    local path=$1 name=${1##*/}
    if [[ -z ${host_library_seen[$name]+present} ]]; then
        host_library_seen[$name]=present
        host_library_names+=("$name")
    fi
}

host_roots=(libgtk-3.so.0 libwebkit2gtk-4.1.so.0)
for executable in "$PREFIX_DIR/usr/bin/emacs" "$PREFIX_DIR/usr/bin/emacsclient"; do
    while IFS= read -r name; do
        [[ -n ${private_root_seen[$name]+present} ]] || host_roots+=("$name")
    done < <(readelf -d "$executable" | awk -F'[][]' '/NEEDED/ { print $2 }')
done

declare -A host_root_seen=()
for root in "${host_roots[@]}"; do
    [[ -n ${host_root_seen[$root]+present} ]] && continue
    host_root_seen[$root]=present
    root_path=$(resolve_library "$root")
    if ! closure=$(lddtree -l "$root_path"); then
        printf 'Cannot compute host dependency closure for %s\n' "$root" >&2
        exit 1
    fi
    while IFS= read -r path; do
        [[ $path == /* ]] && add_host_library "$path"
    done <<<"$closure"
done
#+end_src

When copying a private dependency, I skip it if it belongs to the host, unless
it is one of the ImageMagick exceptions above, and I copy the real library file
and recreate its SONAME symlink.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
copy_private_library() {
    local path=$1 name=${1##*/} real real_name
    if [[ -n ${host_library_seen[$name]+present} \
          && -z ${forced_private_library[$name]+present} ]]; then
        return
    fi
    real=$(readlink -f "$path")
    [[ -f $real ]] || { printf 'Cannot copy dependency %s\n' "$path" >&2; exit 1; }
    real_name=${real##*/}
    if [[ ! -e $private_lib/$real_name ]]; then
        cp -a "$real" "$private_lib/$real_name"
    fi
    if [[ $name != "$real_name" && ! -e $private_lib/$name ]]; then
        ln -s "$real_name" "$private_lib/$name"
    fi
}

deploy_private_dependencies() {
    local root=$1 root_real path
    root_real=$(readlink -f "$root")
    if ! closure=$(lddtree -l "$root"); then
        printf 'Cannot compute private dependency closure for %s\n' "$root" >&2
        exit 1
    fi
    while IFS= read -r path; do
        [[ $path == /* ]] || continue
        [[ $(readlink -f "$path") == "$root_real" ]] && continue
        copy_private_library "$path"
    done <<<"$closure"
}

deploy_private_root() {
    copy_private_library "$1"
    deploy_private_dependencies "$1"
}

deploy_private_root "$magick_wand"
deploy_private_root "$magick_core"
deploy_private_root "$libgccjit_root"
deploy_private_root "$tree_sitter_root"
while IFS= read -r -d '' module; do
    deploy_private_dependencies "$module"
done < <(find "$PREFIX_DIR/usr/lib/ImageMagick" -type f -name '*.so*' -print0)
#+end_src

* Native compilation

I want native compilation to work on machines without GCC or development
packages, so the archive contains a small toolchain: the GCC driver,
~collect2~, assembler, linker, and the libraries needed by these programs.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
printf 'Deploying native-compilation toolchain...\n'
toolchain="$PREFIX_DIR/usr/libexec/native-comp"
tool_bin="$toolchain/bin"
tool_lib="$toolchain/lib"
tool_gcc="$toolchain/lib/gcc/$GCC_TRIPLET/$GCC_VERSION"
mkdir -p "$tool_bin" "$tool_lib" "$tool_gcc"

GCC_DRIVER_SOURCE=/usr/bin/$GCC_TRIPLET-gcc-$GCC_VERSION
[[ -x $GCC_DRIVER_SOURCE ]] || GCC_DRIVER_SOURCE=$(command -v "$BUILD_GCC")
install -m755 "$GCC_DRIVER_SOURCE" "$tool_bin/$GCC_TRIPLET-gcc-$GCC_VERSION"
install -m755 "$(readlink -f "$(command -v as)")" "$tool_bin/as"
install -m755 "$(readlink -f "$(command -v ld)")" "$tool_bin/ld"
install -m755 "$($BUILD_GCC -print-prog-name=collect2)" "$tool_gcc/collect2"

declare -A tool_library_seen=()
copy_tool_library() {
    local path=$1 name=${1##*/} real real_name
    case "$name" in
        ld-linux*.so.*|libc.so.*|libm.so.*|libpthread.so.*|libdl.so.*|librt.so.*)
            return ;;
    esac
    real=$(readlink -f "$path")
    [[ -f $real ]] || return
    real_name=${real##*/}
    if [[ -z ${tool_library_seen[$real_name]+present} ]]; then
        cp -a "$real" "$tool_lib/$real_name"
        tool_library_seen[$real_name]=present
    fi
    if [[ $name != "$real_name" && ! -e $tool_lib/$name ]]; then
        ln -s "$real_name" "$tool_lib/$name"
    fi
}

for executable in "$tool_bin/as" "$tool_bin/ld"; do
    while IFS= read -r path; do
        [[ $path == /* ]] && copy_tool_library "$path"
    done < <(lddtree -l "$executable")
done

#+end_src

Native Lisp shared objects do not need the usual C startup files, so the site
file passes ~-nostdlib~ and points GCC at the private tools, and the host does
not need libc development files. It changes ~PATH~ only while Emacs starts a
native compilation worker, other subprocesses still see the user's normal
commands, and because this is a site file, ~emacs -Q~ does not load it.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
mkdir -p "$PREFIX_DIR/usr/share/emacs/site-lisp"
cat >"$PREFIX_DIR/usr/share/emacs/site-lisp/site-start.el" <<EOF
;;; site-start.el --- portable native compiler setup -*- lexical-binding: t; -*-

(defvar emacs-portable--native-comp-bin nil)

(let* ((site-directory (file-name-directory (or load-file-name buffer-file-name)))
       (prefix (expand-file-name "../../.." site-directory))
       (toolchain (expand-file-name "libexec/native-comp/" prefix)))
  (setq native-comp-driver-options
        (list "-nostdlib"
              (concat "-B" toolchain "bin/")
              (concat "-B" toolchain
                      "lib/gcc/$GCC_TRIPLET/$GCC_VERSION/"))
        emacs-portable--native-comp-bin
        (expand-file-name "bin" toolchain)))

(defun emacs-portable--with-native-comp-path (function &rest arguments)
  (let ((process-environment (copy-sequence process-environment)))
    (setenv "PATH" (concat emacs-portable--native-comp-bin
                            path-separator (or (getenv "PATH") "")))
    (apply function arguments)))

(advice-add 'comp--native-compile :around
            #'emacs-portable--with-native-comp-path)
(advice-add 'comp--run-async-workers :around
            #'emacs-portable--with-native-comp-path)
EOF
#+end_src

* Making the installation relocatable

There is no wrapper around Emacs, every ELF file gets a RUNPATH relative to
~$ORIGIN~, Emacs and its tools find ~lib/private~, while the compiler tools find
their own library directory. This works without setting ~LD_LIBRARY_PATH~ for
programs started from Emacs.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
printf 'Patching ELF RUNPATHs and packaging archive...\n'
patch_runpath() {
    local elf=$1 destination=$2 relative runpath type
    if ! type=$(readelf -h "$elf" 2>/dev/null | awk '/Type:/ { print $2; exit }'); then
        return 0
    fi
    [[ $type == DYN || $type == EXEC ]] || return 0
    relative=$(realpath --relative-to="$(dirname "$elf")" "$destination")
    if [[ $relative == . ]]; then
        runpath='$ORIGIN'
    else
        runpath="\$ORIGIN/$relative"
    fi
    patchelf --set-rpath "$runpath" "$elf"
}

while IFS= read -r -d '' elf; do
    [[ $elf == "$toolchain/"* ]] && continue
    patch_runpath "$elf" "$private_lib"
done < <(find "$PREFIX_DIR/usr" -type f -print0)
while IFS= read -r -d '' elf; do
    patch_runpath "$elf" "$tool_lib"
done < <(find "$toolchain" -type f -print0)
#+end_src

Before packaging, I check once more that none of the host libraries ended up in
~lib/private~.

#+begin_src bash :tangle build-bundle.sh :tangle-mode (identity #o755)
for library in "${host_library_names[@]}"; do
    [[ -n ${forced_private_library[$library]+present} ]] && continue
    if find "$private_lib" \( -type f -o -type l \) -name "$library" \
            -print -quit | grep -q .; then
        printf 'Host platform library was bundled unexpectedly: %s\n' "$library" >&2
        exit 1
    fi
done

icon=$(find "$PREFIX_DIR/usr/share/icons" -type f -name emacs.svg -print -quit)
[[ -n $icon ]] || { echo 'The Emacs installation did not contain emacs.svg' >&2; exit 1; }
cp "$ROOT/Emacs.desktop" "$PREFIX_DIR/usr/Emacs.desktop"
cp "$icon" "$PREFIX_DIR/usr/Emacs.svg"

for command in emacs emacsclient; do
    [[ -x $PREFIX_DIR/usr/bin/$command ]] || {
        printf 'Missing installed command: %s\n' "$command" >&2
        exit 1
    }
done

rm -rf "$BUILD_DIR/package"
mkdir -p "$BUILD_DIR/package/$PACKAGE_NAME"
final_prefix="$BUILD_DIR/package/$PACKAGE_NAME"
cp -a "$PREFIX_DIR/usr"/. "$final_prefix/"
#+end_src

The result still uses the normal Emacs binary, and the ~environment.sh~ file
sets the paths for Lisp, data, helper programs, native Lisp, and ImageMagick. It
also adds the archive's normal ~bin~ directory to ~PATH~, but does not add the
private compiler directory.

export MAGICK_CODER_MODULE_PATH="\$_emacs_prefix/lib/ImageMagick/coders"
export MAGICK_FILTER_MODULE_PATH="\$_emacs_prefix/lib/ImageMagick/filters"
export EMACSDATA="\$_emacs_prefix/share/emacs/$EMACS_VERSION/etc"
export EMACSDOC="\$_emacs_prefix/share/emacs/$EMACS_VERSION/etc"
export EMACSPATH="\$_emacs_prefix/libexec/emacs/$EMACS_VERSION/$EMACS_ARCH"
export EMACSLOADPATH="\$_emacs_prefix/share/emacs/site-lisp:\$_emacs_prefix/share/emacs/$EMACS_VERSION/lisp"
export EMACSNATIVELOADPATH="\$_emacs_prefix/lib/emacs/$EMACS_VERSION/native-lisp"

dump_files=("$final_prefix/libexec/emacs/$EMACS_VERSION/$EMACS_ARCH"/*.pdmp)
if ((${#dump_files[@]} != 1)); then
    printf 'Expected one portable dump, found %d\n' "${#dump_files[@]}" >&2
    exit 1
fi
emacs_binary=$(readlink -f "$final_prefix/bin/emacs")

dump_target="../libexec/emacs/$EMACS_VERSION/$EMACS_ARCH/${dump_files[0]##*/}"
ln -s "$dump_target" "$dump_link"

output_path="$OUTPUT_DIR/$OUTPUT_NAME"
tar --zstd --sort=name --mtime='UTC 1970-01-01' \
    --owner=0 --group=0 --numeric-owner \
    -C "$BUILD_DIR/package" -cf "$output_path" "$PACKAGE_NAME"
(
  cd "$OUTPUT_DIR"
  sha256sum "$OUTPUT_NAME" >"$OUTPUT_NAME.sha256"

printf 'Created %s/%s\n' "$OUTPUT_DIR" "$OUTPUT_NAME"

* Verification

I treat verification as part of the build, and the scripts under
~.github/scripts/~ check archive integrity, the host/private ELF boundary,
relative RUNPATHs, relocation, portable-dump discovery, configured features,
subprocess lookup, native compilation, ~emacsclient~, ImageMagick decoding, and
XWidget creation.

The container verifier installs runtime libraries—but no compiler, libgccjit,
or development packages—in clean Debian, Ubuntu, and Fedora images. Ubuntu
24.04 also represents the library baseline used by current Linux Mint.

Run the complete experiment locally with:

#+begin_src sh
emacs --batch --quick --eval '(require (quote org))' \
  --eval '(org-babel-tangle-file "README.org")'
podman build -t emacs-portable-builder -f Containerfile .
podman run --rm -e EMACS_REF -e BUNDLE_ARCH \
  -v "$PWD:/work" emacs-portable-builder
.github/scripts/verify-containers.sh dist/Emacs-*.tar.zst
#+end_src

* Installation

Verify the checksum, extract the matching architecture, and add its real ~bin~
directory to the normal user path:

tar --zstd -xf dist/Emacs-*.tar.zst -C "$HOME/.local/opt"
prefix=$(find "$HOME/.local/opt" -maxdepth 1 -type d -name 'Emacs-*' -print -quit)
. "$prefix/environment.sh"
emacs
#+end_src

Source ~environment.sh~ from the shell or session that starts Emacs, it sets
Emacs installation paths, prepends the normal ~bin~ directory, and exports the
bundled ImageMagick paths, while the private native-comp tool directory is only
added when compilation workers are started.

The host must provide the runtime GTK 3 and WebKitGTK 4.1 packages, but no host
GCC, libgccjit, binutils, or development package is required.

* Monthly builds

On the first day of each month GitHub Actions builds x86_64 and AArch64
archives, verifies them in Debian, Ubuntu, and Fedora containers, and publishes
them with checksums, while manual runs can override ~EMACS_REF~ when I want to
test a particular Emacs revision.
