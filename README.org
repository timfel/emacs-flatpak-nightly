* Overview

This document is the complete source for building Emacs ~master~ as a PGTK
(native Wayland) AppImage for Linux. The build enables native compilation,
tree-sitter, the built-arser, ImageMagick, XWidgets, D-Bus, dynamic modules,
file notifications, sound, SVG, XPM, and the usual image formats.

An [[https://appimage.org/][AppImage]] is a deployment bundle, not a andbox. Emacs can use the host
filesystem, D-Bus session, devices, environment, and commands directly. The
artifact contains Emacs and its non-core runtime dependencies, but uses the
host kernel, display server, and other fundamental system facilities. While
AppImages may be less popular than e.g. Flatpaks, Emacs really benefits from
unrestricted system access, so this distribution format seems more suitable.

The compilation environment is Ubuntu 22.04, which gives the result a
reasonably old glibc baseline so it should work on many current Linux
distributions.

Emacs follows a moving Git branch by default, so this is a rolling build.
~EMACS_REF~ can select a branch, tag, or commit when a fixed input is desired.

* Builder container

The container supplies compilation headers and tools. Runtime libraries are
subsequently selected from this old userspace and copied into the AppDir.

* AppImage launcher

AppImage uses the [[https://docs.appimage.org/reference/appdir.html][AppDir]] specification to lay out a bundle. The entry point is
always called ~AppRun~. For Emacs, we have two interesting binaries a user might
want to launch: =emacs= and =emacsclient=. To support both, we use a custom
launcher. A shell script would lose useful control over ~argv[0]~ while passing
through its interpreter. Instead, we use a small C program.

#+begin_src c :tangle AppRun.c
#define _GNU_SOURCE

#include <errno.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

#ifndef EMACS_VERSION
#error "EMACS_VERSION must be supplied by the build"
#endif
#ifndef EMACS_ARCH
#error "EMACS_ARCH must be supplied by the build"
#endif
#ifndef SYSTEM_ARCH
#error "SYSTEM_ARCH must be supplied by the build"
#endif
#ifndef GCC_VERSION
#error "GCC_VERSION must be supplied by the build"
#endif
#ifndef GCC_TRIPLET
#error "GCC_TRIPLET must be supplied by the build"
#endif

static void fail(const char *message)
{
  fprintf(stderr, "Emacs AppImage: %s: %s\n", message, strerror(errno));
  exit(127);
}
#+end_src

The AppImage runtime deliberately sets the ~ARGV0~ environment variable its own
incoming ~argv[0]~, preserving both a symlink launch name and a name supplied
with ~exec -a~.

#+begin_src c :tangle AppRun.c
static const char *original_launch_name(int argc, char **argv)
{
  const char *name = getenv("ARGV0");
  if (!name || !*name)
    name = argc > 0 ? argv[0] : "emacs";
  const char *slash = strrchr(name, '/');
  return slash ? slash + 1 : name;
}
#+end_src

Some environment variables like ~$PATH~ can contain multiple entries, so we just
extend with the AppImage specific contents instead of overriding. This allows
the Emacs process to find its own =etags= and =ebrowse= binaries, for example.

#+begin_src c :tangle AppRun.c
static void prepend_env(const char *name, const char *value)
{
    const char *old = getenv(name);
    size_t length = strlen(value) + (old && *old ? strlen(old) + 1 : 0) + 1;
    char *combined = malloc(length);
    if (!combined)
        fail("out of memory");
    if (old && *old)
        snprintf(combined, length, "%s:%s", value, old);
    else
        snprintf(combined, length, "%s", value);
    if (setenv(name, combined, 1) < 0)
        fail("setenv");
    free(combined);
}
#+end_src

After dispatching, the launcher establishes paths relative to ~$APPDIR~ for Emacs
Lisp, native Lisp, GCC JIT, helper programs, shared libraries, GTK data, and
WebKit. It then replaces itself with the selected program and passes every
argument through unchanged.

#+begin_src c :tangle AppRun.c
int main(int argc, char **argv)
{
    char appdir[PATH_MAX];
    const char *from_env = getenv("APPDIR");
    if (from_env && *from_env) {
        if (snprintf(appdir, sizeof(appdir), "%s", from_env) >= (int)sizeof(appdir)) {
            errno = ENAMETOOLONG;
            fail("APPDIR");
        }
    } else {
        ssize_t length = readlink("/proc/self/exe", appdir, sizeof(appdir) - 1);
        if (length < 0)
            fail("cannot locate AppRun");
        appdir[length] = '\0';
        char *slash = strrchr(appdir, '/');
        if (!slash) {
            errno = EINVAL;
            fail("cannot locate AppDir");
        }
        *slash = '\0';
    }

    char bindir[PATH_MAX], library_path[PATH_MAX * 2], data[PATH_MAX];
    char gcc_prefix[PATH_MAX], gcc_compilers[PATH_MAX * 2];
    char gcc_libraries[PATH_MAX * 3];
    char exec_path[PATH_MAX], lisp_path[PATH_MAX * 2], native_path[PATH_MAX];
    char target[PATH_MAX], xdg_data[PATH_MAX], gio_modules[PATH_MAX];
    char schemas[PATH_MAX], gi_types[PATH_MAX], gtk_path[PATH_MAX];
    char gtk_im_modules[PATH_MAX], pixbuf_modules[PATH_MAX];
    char webkit_path[PATH_MAX], webkit_bundle[PATH_MAX], gtk_prefix[PATH_MAX];

#define FORMAT(destination, ...)                                                \
    do {                                                                        \
        if (snprintf((destination), sizeof(destination), __VA_ARGS__) >=         \
            (int)sizeof(destination)) {                                          \
            errno = ENAMETOOLONG;                                                \
            fail("AppDir path");                                                \
        }                                                                       \
    } while (0)

    FORMAT(bindir, "%s/usr/bin", appdir);
    FORMAT(library_path, "%s/usr/lib:%s/usr/lib/" SYSTEM_ARCH, appdir, appdir);
    FORMAT(gcc_prefix, "%s/usr/lib/gcc/", appdir);
    FORMAT(gcc_compilers, "%s/usr/libexec/gcc/%s/" GCC_VERSION ":%s/usr/bin",
           appdir, GCC_TRIPLET, appdir);
    FORMAT(gcc_libraries,
           "%s/usr/lib/gcc/%s/" GCC_VERSION ":%s/usr/lib/" SYSTEM_ARCH ":%s/usr/lib",
           appdir, GCC_TRIPLET, appdir, appdir);
    FORMAT(data, "%s/usr/share/emacs/" EMACS_VERSION "/etc", appdir);
    FORMAT(exec_path, "%s/usr/libexec/emacs/" EMACS_VERSION "/" EMACS_ARCH, appdir);
    FORMAT(lisp_path, "%s/usr/share/emacs/site-lisp:%s/usr/share/emacs/" EMACS_VERSION "/lisp", appdir, appdir);
    FORMAT(native_path, "%s/usr/lib/emacs/" EMACS_VERSION "/native-lisp", appdir);
    FORMAT(xdg_data, "%s/usr/share", appdir);
    FORMAT(gio_modules, "%s/usr/lib/gio/modules", appdir);
    FORMAT(schemas, "%s/usr/share/glib-2.0/schemas", appdir);
    FORMAT(gi_types, "%s/usr/lib/girepository-1.0", appdir);
    FORMAT(gtk_prefix, "%s/usr", appdir);
    FORMAT(gtk_path, "%s/usr/lib/gtk-3.0", appdir);
    FORMAT(gtk_im_modules, "%s/usr/lib/gtk-3.0/3.0.0/immodules.cache", appdir);
    FORMAT(pixbuf_modules, "%s/usr/lib/gdk-pixbuf-2.0/2.10.0/loaders.cache", appdir);
    FORMAT(webkit_path, "%s/usr/lib/" SYSTEM_ARCH "/webkit2gtk-4.0", appdir);
    FORMAT(webkit_bundle, "%s/injected-bundle", webkit_path);

    prepend_env("PATH", bindir);
    prepend_env("LD_LIBRARY_PATH", library_path);
    prepend_env("COMPILER_PATH", gcc_compilers);
    prepend_env("LIBRARY_PATH", gcc_libraries);
    if (setenv("GCC_EXEC_PREFIX", gcc_prefix, 1) < 0)
        fail("setenv");
    prepend_env("XDG_DATA_DIRS", xdg_data);
    if (setenv("GIO_MODULE_DIR", gio_modules, 1) < 0 ||
        setenv("GIO_EXTRA_MODULES", gio_modules, 1) < 0 ||
        setenv("GTK_DATA_PREFIX", appdir, 1) < 0 ||
        setenv("GSETTINGS_SCHEMA_DIR", schemas, 1) < 0 ||
        setenv("GI_TYPELIB_PATH", gi_types, 1) < 0 ||
        setenv("GTK_EXE_PREFIX", gtk_prefix, 1) < 0 ||
        setenv("GTK_PATH", gtk_path, 1) < 0 ||
        setenv("GTK_IM_MODULE_FILE", gtk_im_modules, 1) < 0 ||
        setenv("GDK_PIXBUF_MODULE_FILE", pixbuf_modules, 1) < 0 ||
        setenv("WEBKIT_EXEC_PATH", webkit_path, 1) < 0 ||
        setenv("WEBKIT_INJECTED_BUNDLE_PATH", webkit_bundle, 1) < 0 ||
        setenv("EMACSDATA", data, 1) < 0 || setenv("EMACSDOC", data, 1) < 0 ||
        setenv("EMACSPATH", exec_path, 1) < 0 ||
        setenv("EMACSLOADPATH", lisp_path, 1) < 0 ||
        setenv("EMACSNATIVELOADPATH", native_path, 1) < 0)
        fail("setenv");

    int client = strcmp(original_launch_name(argc, argv), "emacsclient") == 0;
    FORMAT(target, "%s/%s", bindir, client ? "emacsclient" : "emacs");
    argv[0] = client ? (char *)"emacsclient" : (char *)"emacs";
    execv(target, argv);
    fail(target);
}
#+end_src

** Launch-name behavior

As mentioned, we want both =emacs= and =emacsclient= to be user-invocable through
this single AppImage. Through ~ARGV0~ inspecting code above, one artifact can
provide both commands, by symlinking or using ~exec -a~. Only when executed with
the name =emacsclient= will the AppRun launcher invoke that binary, all other
names will launch =emacs=.

#+begin_src sh
appimage="$PWD/Emacs-EMACS_VERSION-ARCH.AppImage"
ln -s "$appimage" "$HOME/.local/bin/emacsclient"
exec -a emacsclient "$appimage" -c
#+end_src

* Desktop metadata

A ~.desktop~ file is copied to the AppDir root alongside Emacs's own scalable
icon. During dependency deployment its ~Exec~ field temporarily names the bundled
~emacs~ executable, because linuxdeploy resolves the command while processing the
desktop file. The build changes it back to the architecture-specific AppImage
filename after linuxdeploy has finished, so desktop integration launches this
artifact.

#+begin_src conf :tangle Emacs.desktop
[Desktop Entry]
Type=Application
Name=Emacs
GenericName=Text Editor
Comment=Edit text with Emacs
Exec=emacs %F
Icon=Emacs
Terminal=false
Categories=Development;TextEditor;
MimeType=text/plain;
StartupWMClass=Emacs
#+end_src

* Build driver

The driver first prepares the build tools. AppImages used as build tools are
run in extract-and-run mode by setting ~APPIMAGE_EXTRACT_AND_RUN=1~, so building
works in containers and CI workers which do not expose FUSE.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
#!/usr/bin/env bash
set -euo pipefail

ROOT=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)
BUILD_DIR=${BUILD_DIR:-"$ROOT/.build"}
APPDIR=${APPDIR:-"$ROOT/AppDir"}
OUTPUT_DIR=${OUTPUT_DIR:-"$ROOT/dist"}
EMACS_REPOSITORY=${EMACS_REPOSITORY:-https://github.com/emacs-mirror/emacs.git}
EMACS_REF=${EMACS_REF:-master}
JOBS=${JOBS:-$(nproc)}

export APPIMAGE_EXTRACT_AND_RUN=1

APPIMAGE_ARCH=${APPIMAGE_ARCH:-$(uname -m)}
case "$APPIMAGE_ARCH" in
    x86_64|amd64) APPIMAGE_ARCH=x86_64 ;;
    aarch64|arm64) APPIMAGE_ARCH=aarch64 ;;
    *)
        printf 'Unsupported AppImage architecture: %s\n' "$APPIMAGE_ARCH" >&2
        exit 1
        ;;
esac

rm -rf "$BUILD_DIR" "$APPDIR"
mkdir -p "$BUILD_DIR/tools" "$OUTPUT_DIR"
rm -f "$OUTPUT_DIR"/Emacs.AppImage \
      "$OUTPUT_DIR"/Emacs.AppImage.sha256 \
      "$OUTPUT_DIR"/Emacs-*.AppImage \
      "$OUTPUT_DIR"/Emacs-*.AppImage.sha256

download_tool() {
    local url=$1 destination=$2
    curl --fail --location --retry 5 --output "$destination" "$url"
    chmod +x "$destination"
}

download_tool \
  "https://github.com/linuxdeploy/linuxdeploy/releases/download/continuous/linuxdeploy-${APPIMAGE_ARCH}.AppImage" \
  "$BUILD_DIR/tools/linuxdeploy"
download_tool \
  https://raw.githubusercontent.com/linuxdeploy/linuxdeploy-plugin-gtk/master/linuxdeploy-plugin-gtk.sh \
  "$BUILD_DIR/tools/linuxdeploy-plugin-gtk.sh"
download_tool \
  "https://github.com/AppImage/appimagetool/releases/download/continuous/appimagetool-${APPIMAGE_ARCH}.AppImage" \
  "$BUILD_DIR/tools/appimagetool"

export PATH="$BUILD_DIR/tools:$PATH"
#+end_src

_!!! Temporary Hack Time !!!_

A repository checkout omits generated Unicode properties until bootstrap.
compile.el currently contains a named-character escape which needs those
properties while bootstrap-emacs is itself being made. Spell that one character
numerically for the bootstrap pass, then restore the pristine source and let
make rebuild anything affected for the final installation.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
compile_lisp=lisp/progmodes/compile.el
cp "$compile_lisp" "$compile_lisp.bootstrap-original"
trap 'mv -f "$compile_lisp.bootstrap-original" "$compile_lisp" 2>/dev/null || true' EXIT
sed -i 's/?\\N{BULLET}/?\\u2022/g' "$compile_lisp"
make -j"$JOBS" bootstrap
mv "$compile_lisp.bootstrap-original" "$compile_lisp"
trap - EXIT
make -j"$JOBS"
make install DESTDIR="$APPDIR"
#+end_src

Instead of hardcoding installation names or duplicating Emacs' version naming
rules, we determine installation names.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
shopt -s nullglob
version_dirs=("$APPDIR"/usr/share/emacs/[0-9]*)
if ((${#version_dirs[@]} != 1)); then
    printf 'Expected one Emacs version directory, found %d\n' "${#version_dirs[@]}" >&2
    exit 1
fi
EMACS_VERSION=${version_dirs[0]##*/}
arch_dirs=("$APPDIR/usr/libexec/emacs/$EMACS_VERSION"/*)
if ((${#arch_dirs[@]} != 1)); then
    printf 'Expected one Emacs architecture directory, found %d\n' "${#arch_dirs[@]}" >&2
    exit 1
fi
EMACS_ARCH=${arch_dirs[0]##*/}
OUTPUT_NAME="Emacs-${EMACS_VERSION}-${APPIMAGE_ARCH}.AppImage"
SYSTEM_ARCH=$(dpkg-architecture -qDEB_HOST_MULTIARCH)
#+end_src

GCC's JIT driver needs the matching GCC installation at runtime. Linuxdeploy
only sees the ~libgccjit.so~ dependency, so we need to stage the driver, GCC's
target files, startup objects, and the linker frontends explicitly. The
target-prefixed driver name is the name libgccjit looks up before falling back
to a hard-coded system path.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
GCC_VERSION=12
GCC_BINARY="gcc-${GCC_VERSION}"
GCC_TRIPLET=$($GCC_BINARY -dumpmachine)
GCC_DRIVER_NAME="${GCC_TRIPLET}-gcc-${GCC_VERSION}"
GCC_DRIVER_SOURCE="/usr/bin/${GCC_DRIVER_NAME}"
if [[ ! -x $GCC_DRIVER_SOURCE ]]; then
    GCC_DRIVER_SOURCE=$(command -v "$GCC_BINARY" || true)
fi
if [[ -z $GCC_DRIVER_SOURCE || ! -x $GCC_DRIVER_SOURCE ]]; then
    printf 'Cannot find the GCC %s driver\n' "$GCC_VERSION" >&2
    exit 1
fi

GCC_LIB_DIR=$(dirname "$($GCC_BINARY -print-file-name=libgcc.a)")
GCC_PROGRAM_SOURCE=$($GCC_BINARY -print-prog-name=cc1)
GCC_PROGRAM_DIR=$(dirname "$GCC_PROGRAM_SOURCE")
if [[ ! -d $GCC_LIB_DIR || ! -d $GCC_PROGRAM_DIR || ! -x $GCC_PROGRAM_SOURCE ]]; then
    printf 'Cannot find the GCC %s runtime directories\n' "$GCC_VERSION" >&2
    exit 1
fi
for required in crtbeginS.o crtendS.o libgcc.a; do
    if [[ ! -f $GCC_LIB_DIR/$required ]]; then
        printf 'GCC runtime is missing %s\n' "$required" >&2
        exit 1
    fi
done

mkdir -p "$APPDIR/usr/lib/gcc/$GCC_TRIPLET" \
         "$APPDIR/usr/libexec/gcc/$GCC_TRIPLET" \
         "$APPDIR/usr/lib/$SYSTEM_ARCH"
cp -a "$GCC_LIB_DIR" "$APPDIR/usr/lib/gcc/$GCC_TRIPLET/"
if [[ $GCC_PROGRAM_DIR == "$GCC_LIB_DIR" ]]; then
    ln -s "../../../lib/gcc/$GCC_TRIPLET/$GCC_VERSION" \
        "$APPDIR/usr/libexec/gcc/$GCC_TRIPLET/$GCC_VERSION"
else
    cp -a "$GCC_PROGRAM_DIR" "$APPDIR/usr/libexec/gcc/$GCC_TRIPLET/"
fi
install -Dm755 "$GCC_DRIVER_SOURCE" "$APPDIR/usr/bin/$GCC_DRIVER_NAME"

for tool in as ld; do
    tool_source=$(command -v "$tool")
    install -Dm755 "$(readlink -f "$tool_source")" "$APPDIR/usr/bin/$tool"
done

for support in \
    crt1.o Scrt1.o crti.o crtn.o rcrt1.o \
    libc.so libc_nonshared.a libm.so libmvec.so libmvec_nonshared.a \
    libdl.so libpthread.so librt.so libgcc_s.so.1; do
    support_source=$($GCC_BINARY -print-file-name="$support")
    if [[ $support_source != "$support" && -f $support_source ]]; then
        install -Dm644 "$support_source" "$APPDIR/usr/lib/$SYSTEM_ARCH/$support"
    fi
done

gcc_deploy_args=(
    --executable "$APPDIR/usr/bin/$GCC_DRIVER_NAME"
    --executable "$APPDIR/usr/bin/as"
    --executable "$APPDIR/usr/bin/ld"
    --library "$APPDIR/usr/lib/$SYSTEM_ARCH/libgcc_s.so.1"
)
#+end_src

GIO is compiled against an old GLib on purpose. This can be incompatible with
the host GLib (the host dconf module is one example), so we also copy the
matching modules from the Ubuntu build environment and make that directory
exclusive at runtime.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
gio_modules_source="/usr/lib/$SYSTEM_ARCH/gio/modules"
if [[ ! -d $gio_modules_source ]]; then
    echo "Cannot find $gio_modules_source" >&2
    exit 1
fi
mkdir -p "$APPDIR/usr/lib/gio"
cp -a "$gio_modules_source" "$APPDIR/usr/lib/gio/"
gio_deploy_args=()
while IFS= read -r -d '' module; do
    gio_deploy_args+=(--library "$module")
done < <(find "$APPDIR/usr/lib/gio/modules" -type f -name '*.so*' -print0)
#+end_src

The WebKit support needs a bit of special handling. WebKit launchers helper
processes and dlopens its injected bundle, so these do not appear in Emacs's
DT_NEEDED list. We preserve WebKit's directory layout and explicitly ask
linuxdeploy to process every helper and shared object.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
webkit_source="/usr/lib/$SYSTEM_ARCH/webkit2gtk-4.0"
if [[ ! -d $webkit_source ]]; then
    echo "Cannot find $webkit_source" >&2
    exit 1
fi
mkdir -p "$APPDIR/usr/lib/$SYSTEM_ARCH"
cp -a "$webkit_source" "$APPDIR/usr/lib/$SYSTEM_ARCH/"
webkit_deploy_args=()
while IFS= read -r -d '' helper; do
    webkit_deploy_args+=(--executable "$helper")
done < <(find "$APPDIR$webkit_source" -type f -executable -print0)
while IFS= read -r -d '' library; do
    webkit_deploy_args+=(--library "$library")
done < <(find "$APPDIR$webkit_source" -type f -name '*.so*' -print0)
#+end_src

Now we are ready to create the AppDir from which we'll build the final
AppImage. Linuxdeploy installs the ELF dependencies and GTK/WebKit support
files into ~$APPDIR~.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
icon=$(find "$APPDIR/usr/share/icons" -type f -name 'emacs.svg' -print -quit)
if [[ -z $icon ]]; then
    echo 'The Emacs installation did not contain emacs.svg' >&2
    exit 1
fi
cp "$ROOT/Emacs.desktop" "$APPDIR/Emacs.desktop"
cp "$icon" "$APPDIR/Emacs.svg"

NO_STRIP=1 linuxdeploy \
  --appdir "$APPDIR" \
  --executable "$APPDIR/usr/bin/emacs" \
  --executable "$APPDIR/usr/bin/emacsclient" \
  --desktop-file "$APPDIR/Emacs.desktop" \
  --icon-file "$APPDIR/Emacs.svg" \
  "${gcc_deploy_args[@]}" \
  "${gio_deploy_args[@]}" \
  "${webkit_deploy_args[@]}" \
  --plugin gtk
#+end_src

Emacs looks for its portable dump before it processes ~EMACSPATH~, so that
variable cannot relocate the compile-time ~/usr/libexec~ dump path into the
AppDir. Its first lookup is beside the resolved executable, using the executable
basename plus ~.pdmp~. The installation has a single fingerprinted dump under
~usr/libexec~; expose it at that first lookup location with a relative symlink.
Do this after linuxdeploy has finished modifying the executable.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
dump_files=("$APPDIR/usr/libexec/emacs/$EMACS_VERSION/$EMACS_ARCH"/*.pdmp)
if ((${#dump_files[@]} != 1)); then
    printf 'Expected one Emacs portable dump, found %d\n' "${#dump_files[@]}" >&2
    exit 1
fi
emacs_binary=$(readlink -f "$APPDIR/usr/bin/emacs")
if [[ ! -x $emacs_binary || $emacs_binary != "$APPDIR/usr/bin/"* ]]; then
    echo 'Cannot resolve the installed Emacs executable' >&2
    exit 1
fi
dump_link="$APPDIR/usr/bin/${emacs_binary##*/}.pdmp"
dump_target="../libexec/emacs/$EMACS_VERSION/$EMACS_ARCH/${dump_files[0]##*/}"
ln -s "$dump_target" "$dump_link"
#+end_src

Now linuxdeploy has finished resolving ~Exec=emacs~ and we can restore the
command intended for the installed AppImage desktop entry. The root desktop
file is a symlink to this copy after deployment, so both locations stay
consistent.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
desktop_file="$APPDIR/usr/share/applications/Emacs.desktop"
sed -i "s/^Exec=emacs %F$/Exec=$OUTPUT_NAME %F/" "$desktop_file"
#+end_src

The last step is to compile our custom launcher, add it as ~AppRun~, and build
the final AppImage.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
gcc-12 -std=c11 -O2 -Wall -Wextra -Werror \
  -DEMACS_VERSION=\"$EMACS_VERSION\" \
  -DEMACS_ARCH=\"$EMACS_ARCH\" \
  -DSYSTEM_ARCH=\"$SYSTEM_ARCH\" \
  -DGCC_VERSION=\"$GCC_VERSION\" \
  -DGCC_TRIPLET=\"$GCC_TRIPLET\" \
  "$ROOT/AppRun.c" -o "$APPDIR/AppRun"
chmod +x "$APPDIR/AppRun"

output_path="$OUTPUT_DIR/$OUTPUT_NAME"
ARCH="$APPIMAGE_ARCH" appimagetool "$APPDIR" "$output_path"
(
  cd "$OUTPUT_DIR"
  sha256sum "$OUTPUT_NAME" >"$OUTPUT_NAME.sha256"
)
printf 'Created %s/%s\n' "$OUTPUT_DIR" "$OUTPUT_NAME"
#+end_src

Smoke-check both the portable dump file is discovered correctly.

#+begin_src bash :tangle build-appimage.sh :tangle-mode (identity #o755)
if ! fingerprint=$("$output_path" --fingerprint); then
    echo 'The AppImage could not load its portable dump' >&2
    exit 1
fi
printf 'Portable dump fingerprint: %s\n' "$fingerprint"
#+end_src

#+begin_src sh

The outputs are architecture-specific files such as
~dist/Emacs-30.0.50-x86_64.AppImage~ and their matching ~.sha256~ files.
Override ~EMACS_REF~, ~APPIMAGE_ARCH~, ~JOBS~, ~BUILD_DIR~, ~APPDIR~, or
~OUTPUT_DIR~ with container environment variables when needed. For example,
~-e EMACS_REF=emacs-30~ selects another branch.

Verify and run the artifact with:

#+begin_src sh
sha256sum --check dist/Emacs-*.AppImage.sha256
chmod +x dist/Emacs-*.AppImage
dist/Emacs-*.AppImage
#+end_src

Where FUSE is unavailable, the AppImage runtime can extract itself to a
temporary directory:

#+begin_src sh
APPIMAGE_EXTRACT_AND_RUN=1 dist/Emacs-*.AppImage --quick
#+end_src
